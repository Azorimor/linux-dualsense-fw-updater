Getting Started & Installation

Download the Linux AppImage or build dualsense-updater from source with Rust, Qt 6, and KDE Kirigami.

Option 1: AppImage (Recommended for Linux Users)

Pre-built x86_64 AppImage releases and .tar.gz archives are available via the Download page (requiring safety acknowledgment) and on GitHub Releases.

Wired USB Connection Required

Firmware inspection and updates operate over USB HID only. Connect your DualSense controller using a reliable USB-C data cable (not Bluetooth, and avoid unpowered USB hubs).

Desktop Runtime Requirements

If your desktop environment does not already include KDE Frameworks 6 QML modules, install your distribution's Qt 6 Kirigami runtime package (for example kirigami / qml6-module-org-kde-kirigami and qqc2-desktop-style). When org.kde.desktop is unavailable, the application automatically falls back to Qt's Fusion style (or respects QT_QUICK_CONTROLS_STYLE).

Option 2: Build from Source

Prerequisites

  • Rust toolchain (Edition 2024) and a C++17 / clang toolchain (for cxx / cxx-qt-build)
  • mold linker (configured for Linux targets in .cargo/config.toml)
  • Qt 6 development packages (Qt6Core, Qt6Gui, Qt6Qml, Qt6Quick, Qt6QuickControls2, and qmake6)
  • KDE Frameworks 6 QML modules (Kirigami and qqc2-desktop-style)
  • hidapi development library (libhidapi-dev / hidapi) and pkg-config
