Getting Started & Installation

Install the Unofficial Linux DualSense Firmware Updater using portable x86_64 or aarch64 (.tar.gz) archives, or by building from source.

Option 1: Portable Archive (.tar.gz)

Pre-built portable .tar.gz archives for both x86_64 (Intel / AMD) and aarch64 (ARM64) Linux are available via the Download page (requiring safety acknowledgment) and on GitHub Releases.

Check your CPU architecture with uname -m, download the matching archive, extract it, and run the application directly:

Official Distribution Policy

Official releases are published only as portable .tar.gz archives on GitHub Releases. Any third-party store or distribution packages (such as Flatpak, AUR, or Snap) are community-maintained.

Wired USB Connection Required

Firmware inspection and updates operate over USB HID only. Connect your DualSense controller using a reliable USB-C data cable (not Bluetooth, and avoid unpowered USB hubs).

Desktop Runtime Requirements

The portable .tar.gz release relies on the Qt 6 and KDE Frameworks 6 (Kirigami) libraries installed on your Linux system rather than bundling them.

  • If you use KDE Plasma 6: These packages are usually already installed, and the app should launch right away.
  • If you use another desktop environment (such as GNOME, Cinnamon, XFCE, or MATE): You will likely need to install the required Qt 6 Kirigami runtime packages manually before running the app.

Maybe out of date

Package names and installation commands vary across Linux distributions and change over time. Because we do not regularly test or maintain instructions for every distro, the commands below may become outdated. If a package name is not found, search your distribution's package manager for kirigami and qqc2-desktop-style (Qt 6 / KF6 versions).

Theme & Styling Behavior

If the native KDE desktop style (org.kde.desktop) is not installed or unavailable on your system, the application will still run by automatically falling back to Qt's built-in Fusion theme. You can also force a specific Qt Quick Controls style by setting the QT_QUICK_CONTROLS_STYLE environment variable before launching the app (for example: QT_QUICK_CONTROLS_STYLE=Fusion ./dualsense-updater).

Option 2: Build from Source

Prerequisites

  • Rust toolchain (Edition 2024) and a C++17 / clang toolchain (for cxx / cxx-qt-build)
  • mold linker (configured for Linux targets in .cargo/config.toml)
  • Qt 6 development packages (Qt6Core, Qt6Gui, Qt6Qml, Qt6Quick, Qt6QuickControls2, and qmake6)
  • KDE Frameworks 6 QML modules (Kirigami and qqc2-desktop-style)
  • Linux USB / GL development libraries: libudev-dev (used by the statically compiled hidapi backend), libusb-1.0-0-dev, libgl-dev, libxkbcommon-dev, and pkg-config
