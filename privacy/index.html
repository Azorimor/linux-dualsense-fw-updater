4. Browser USB Controller Checker (WebHID)

The interactive hardware checker on the Supported Hardware page uses your browser's WebHID API to read DualSense hardware revision metadata directly from a USB-connected controller. All inspection runs 100% locally in your browser — controller data is never transmitted to or stored by any server.

5. Desktop Application Network Requests

The Linux desktop application (dualsense-updater) runs locally on your computer and does not collect telemetry or usage analytics.

  • Official Sony firmware lookup & downloads: When you check for updates or download official firmware, the application connects directly to Sony Interactive Entertainment's public firmware distribution servers (fwupdater.dl.playstation.net). Those requests are subject to Sony's privacy practices.
  • Optional Flash Run Reports: After an update completes or fails, the app can optionally pre-fill a GitHub Issue template with anonymized OS, controller board revision, firmware version, and error metrics (controller serial numbers and local file paths are never included). Nothing is sent automatically; submission occurs only if you explicitly open and post the issue on GitHub.

Emails are received via Google's Gmail service (Google Ireland Limited / Google LLC, certified under the EU-U.S. DPF) and deleted once your request is resolved, unless statutory retention obligations apply.

If you open an issue on GitHub Issues, your submission is publicly visible and governed by GitHub's privacy statement.
